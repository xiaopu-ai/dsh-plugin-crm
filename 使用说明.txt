客户运营台 · 使用说明
======================

这是什么
--------
把几个系统导出的客户表、交易表（Excel / CSV / 飞书多维表格）导进来，插件自己体检、清洗、
合并成「一人一行」、分层；AI 帮你把业务规则聊清楚，找出该联系的人、说清楚为什么、怎么跟进，
还能写报告。

数据都在你自己的电脑上。AI 只看得到编号和统计数字，看不到姓名和手机号。


一、准备（只做一次）
--------------------
1. 一台 Mac。
2. 装 Node.js（22 或更新）：打开 https://nodejs.org ，下载 LTS 版安装包，一路下一步。
3. 一个 DeepSeek 账号（能登录 https://platform.deepseek.com 就行），或者一个 DeepSeek API Key。
   没有也能导数据、看分析，只是「问 AI」用不了。


二、启动
--------
1. 把整个「客户运营台」文件夹放到一个固定的地方，比如「文稿」里。以后别挪；挪了的话再双击启动一次就好。
2. 双击「启动客户运营台.command」。
   - 第一次会下载 DeepSeek Harness（装好以后占约 1 GB，看网速一到几分钟，只下这一次），之后每次二十秒左右就开。
   - 浏览器会自己打开。
   - 弹出的黑色终端窗口别关，关了就停了。下次用再双击。

   如果提示「无法打开」或「无法验证开发者」：
   - 右键这个文件 → 打开 → 打开；
   - 还不行：打开「终端」（启动台里搜「终端」），输入 sh 和一个空格，把这个文件拖进终端窗口，按回车。


三、第一次用
------------
1. 页面弹出「Preview Notice」点 Continue。弹出「Get started」时：
   点 Sign in 登录 DeepSeek 账号，或者点 Add API Key 填 key。
   暂时没有账号也没有 key：点这个框右上角的 × 关掉就行，导数据、看分析都能用，只有「问 AI」用不了。
   没登录的话，每次打开页面这个框都会再弹一次，关掉即可。
   （这个框开着的时候，点左边的菜单没反应，那一下只是把框关掉了，再点一次。）
2. 左边点「Customer Ops」（客户运营台），点「新建数据集」，起个名字，选一个预设：
   - 教育示例：学员、课程、缴费续费；
   - 动力运动：车主、车辆、工单、活动；
   - 经销商网络运营（客户表 + 交付单 + 销售机会）：厂家或总代看经销商，一张全量客户表，加交付单、销售机会。
     这几张表的列名对得上，就不用聊配置：导进来以后点「按预设直接起草」，或者跟助手说一句，
     半分钟出草案，你看一眼点定稿；
   - 车主管理系统导出（不带姓名手机号）：接只给分析导出的系统，按客户编号认人；
   - 从零开始：什么都不预设，全靠和 AI 聊。
   预设只是起点，之后都能改。选了「从零开始」也没关系：导进来的表某个预设认识的话，会自己提出来。
3. 最省事的做法：把几张表直接拖到右边的对话栏，说一句「帮我上传和分析」，按它问的选，
   对话里出现卡片就点。想一步一步自己点，就跟着「数据源」页上面的六步走，每一步只有一个主要按钮：
   导入 → 体检 → 定截止日 → 和 AI 聊配置 → 清洗合并 → 复核。
   「和 AI 聊配置」这一步，AI 会看你的表，问你几个拿不准的地方（哪列是什么、怎么分层），
   起草一份配置，你点「定稿」。
4. 想先试一试：用「示例数据」文件夹里的表（全是编的人和数）：
   教育示例 → 选「教育示例」预设；动力运动示例 → 选「动力运动」预设。
   经销商示例 → 选「经销商网络运营」预设，导进来以后点「按预设直接起草」，不用 AI。
   车主系统示例 → 选「车主管理系统导出」预设。
   里面的「第二次导出」是模拟下个月又导了一批，可以先不管。


四、平时怎么用
--------------
- 首页：今天有几件事等你处理，各层多少人，和 30 天前比。
- 分析：「发现了什么 · 建议怎么做」——哪批人刚掉进沉睡、谁快到期、哪里缺联系方式……
  每条都能「问 AI 怎么跟进」「看是谁」「挑人跟进」。下面是 30 天流向图，点一条线就看到那批人。
- 客户：按分层、标记筛人，点一行看这个人的全部记录。
- 名单：名单就是「这次要去联系的一批人」。先问 AI 这批人怎么跟进，再生成名单导出 Excel
  给销售打电话；下次导入新数据，看谁真的来了。
- 经销商（或者门店、校区，按你的数据怎么叫）：每家一行，客户多少、线索跟得快不快、成交率、
  还有多少线索压着没跟、哪家的客户有权益快到期。上面先挑出最该管的几家；点一行看这一家的明细。
  有大区、区域经理的话可以按它汇总。
- 触达：这些客户里有多少人联系得上（加了企微、电话接通过、注册了小程序、是会员），
  有多少人哪个渠道都联系不上；按分层、按经销商、按大区摆开，比整体差的标红。
  点任何一格就看到「这一层里还没有这个渠道的人」，可以直接出名单发下去补。
  第一次打开要是空的，点「让 AI 把触达渠道标出来」，它会问你两三个问题再改配置。
- 活动：参加活动的人和同层没参加的人比，活动后交易率差多少。
- 报告：AI 起草，你定稿，每个数字都有出处。
- 右边的 AI 助手一直都在，日常的事直接跟它说：问数据、要名单、要报告、改规则都行。
  页面上的「问 AI」按钮只会把问题填进它的输入框，你可以改完再发。
  要你拍板的事（定稿、确认日期、生成名单）它会在对话里放一张卡片，你点一下。
- 它说到哪，左边的看板就切到哪。比如问「首跟超时的线索压在哪些经销商手里」，
  左边会自己换到线索页、筛好「首跟超时」、按经销商拆开，不用你去点。
- 要文件也跟它说：「把待处理的线索导出来」「给这批人出个名单」「报告导出 Word」。
  它放一张卡片，你点卡片上的导出按钮，文件就下载了。导出的表默认把姓名遮住。
- 它提议改规则（比如加一个「常客」标记）：卡片上点「采纳」，再点「定稿并清洗」，看板就按新规则算了。
- 数据怎么算也跟它说，不用自己改设置。比如：
  「交付单里的试乘试驾车别算」「原表标了重复的行不要」——它改好给你一张卡片，写着去掉了多少行；
  「给我标出首保还没用、60 天内失效的车主」「按产品线看人，买了两条线以上的单独标出来」；
  「买车是几年一次的事，买了一年多不算流失」——看板就不再把这批人画成变差。
  卡片上「值得再看一眼」的几条先读一下再点定稿：那是这样改会带来的后果，它会用大白话说。
  卡片上还有一段「和现在用的配置比，有几处不一样」：这是插件自己比出来的，不是它说的。
  标红的「少了」要特别看一眼：是你要它去掉的就没事，不是的话跟它说「把 XX 补回去」。
- 要发给各家去跟，说「分别发给每家经销商」：导出来是一个压缩包，里面每家一个文件，
  每家只看得到自己的线索或名单。只是自己统一盯着看，就不用分，一个文件里一家一张表。
  给大区经理看的那种，说「给我一份经销商对比表」，只有数字，没有客户姓名。
- 要给每家一份它自己的成绩单，说「给每家经销商出一份经营简报」：每家一份 Word（一两页），
  写着它的数和全部经销商、和同大区的比，要先做哪几件事；可以各附一份它自己待处理的线索。
  里面的数都是看板上的，没有客户姓名。经销商页最下面的「发下去」里也有这个按钮。
- 要补缺口，说「把刚买车还没加企微的人出一份名单，每家一份」：它按「没有某个标记」圈人。
  这样的名单不看成交，看标记：下个月把新导出的表拖进来以后，打开「名单」页，
  它会告诉你这批人里有多少加上了企微，当时同样没加、没进名单的人里又有多少加上了。
  还没导新数据时，那里写的是「等下一期数据」。

每月导一次新数据：把新导出的表直接拖到右边的对话栏（或页面任何地方；点输入框的「+」选文件也行）。同一张表的新一期会自己对上、
自己清洗；新表的日期比上次晚，会问你一句「截止日改成 X？」。导完输入框里已经放好一句话，回车，
助手就告诉你这个月哪里变了。


五、数据放在哪
--------------
- 你的数据集：「文稿 / 客户运营」，每个数据集一个文件夹（原始文件、清洗结果、名单、报告都在里面）。
- 登录信息、对话记录：你的用户目录下的隐藏文件夹 .dsh-crm-ops。
- 删掉「客户运营台」文件夹不会删数据。


六、已经装了 DeepSeek Harness 桌面版？
--------------------------------------
桌面版 0.2.2-rc.1 或更新可以不用一键启动：Plugins（插件）→ Add plugin（添加插件）→
Install a third-party plugin（安装第三方插件），填「客户运营台」里 dsh-crm-ops 文件夹的完整路径，点 Install。
（版本旧的话先升级，或者还是用上面的一键启动。）
